Introducing the new NanoS3 from Unexpected Maker

NANOS3 is the world’s second smallest, fully-featured ESP32-S3 module!

It's packed with amazing features and peripherals, wireless connectivity and stacks of Flash and PSRAM, all in the same tiny package size as the original TinyPICO Nano, and it's drop in compatible too!







Features

  • Dual 32bit Xtensa LX7 cores @ up to 240Mhz
  • RISC-V Ultra Low Power Co-processor
  • 2.4GHz Wifi - 802.11b/g/n
  • BLE 5.0 + Mesh
  • 8MB QSPI Flash
  • 8MB of extra QSPI PSRAM
  • 700mA 3.3V LDO Regulator
  • ULTRA LOW Deep Sleep Current
  • Low power RGB LED
  • Native USB + USB Serial JTAG
  • D+/D- pins for external USB connector
  • LiPo Battery Charging
  • 3D High Gain Antenna<
  • 27 GPIO
  • Only 28 x 12.7mm in size
  • Compatible with TinyPICO Nano
