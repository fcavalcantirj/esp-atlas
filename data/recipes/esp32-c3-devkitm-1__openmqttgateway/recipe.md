# esp32-c3-devkitm-1 x openmqttgateway

OpenMQTTGateway's board guide lists the `esp32c3-dev-m1-ble` PlatformIO environment as a
"BLE gateway on the C3" targeting `esp32-c3-devkitm-1`; it flashes via the project's
browser-based web installer.
