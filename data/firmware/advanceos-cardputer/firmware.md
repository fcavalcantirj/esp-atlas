AdvanceOS is a lightweight operating system for the M5Cardputer providing media playback, file management, drawing, infrared control, 3D rendering, music composition, gaming, alarm clock, password vault, and voice recording. It can be installed via M5Burner, manual flashing, or the Launcher. 【README】
