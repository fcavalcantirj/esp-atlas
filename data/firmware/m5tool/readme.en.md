    <h1>M5Tool 🛠️💻</h1>
    <p>M5Tool — is a convenient program for flashing M5StickC Plus2/Plus1.1 and Cardputer devices. With M5Tool you can easily install firmware such as Bruce, Nemo, Marauder, CatHack and many others. The program allows you to install the necessary drivers for your device, making the flashing process as simple and convenient as possible.</p>
    <h2>Main features 🌟</h2>
    <ul>
        <li>Support for Bruce, Nemo, Marauder and CatHack firmware.</li>
        <li>Automatic driver installation for the device 🔧.</li>
        <li>Intuitive user interface 🖥️.</li>
        <li>Fast and reliable flashing 🚀.</li>
    </ul>

    <ol>
