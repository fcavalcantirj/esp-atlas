# m5stack-avatar-mic
An example of M5Stack Avatar using a microphone.
The Avatar syncs its mouth movements and tilts according to sound.

# Supported Devices

- M5Stack Core2/Core2 V1.1/AWS
- M5StickC
- M5StickCPlus
- ATOMS3 + PDMUnit
- M5Stack CoreS3
- M5Stack CoreS3SE
- M5Stack Fire
- M5Dial + PDMUnit(Port.A)

# Environment

・VSCode + PlatformIO

If using Arduino IDE, rename as follows:
- src folder -> m5stack-avatar-mic
- main.cpp -> m5stack-avatar-mic.ino
