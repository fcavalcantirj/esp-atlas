The Pip-Boy Weather Clock is a retro-styled weather clock that retrieves weather data via weatherapi.com and synchronizes time using NTP (Network Time Protocol). Configuration settings are loaded from a `config.txt` file stored on an SD card. An onboard LED indicates connection status.
